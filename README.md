# Football Scores

An Angular 9 project created for a football scores app. Only the Angular CLI starter has been committed so far.

## Overview

The repository contains the unmodified project generated by Angular CLI 9.0.7. No football or scores functionality has been implemented: running it shows the Angular CLI welcome page.

## Tech stack

- Angular 9 and TypeScript 3.7
- Karma and Jasmine for unit tests, Protractor for end-to-end tests
- TSLint with Codelyzer

## Getting started

### Prerequisites

Node.js and npm, in versions supported by Angular 9 (for example Node.js 12).

### Install

```sh
npm install
```

### Run locally

```sh
npm start
```

This runs `ng serve`. Open `http://localhost:4200/`; the app reloads when source files change.

### Build

```sh
npm run build
```

This runs `ng build` and writes the output to `dist/`. Add `-- --prod` for a production build.

### Lint

```sh
npm run lint
```

## Project structure

```
src/app/      Root module, routing module and app component (CLI defaults)
src/index.html
e2e/          Protractor end-to-end tests
angular.json  Angular CLI workspace configuration
```

## Tests

```sh
npm test        # unit tests with Karma
npm run e2e     # end-to-end tests with Protractor
```

These are the tests Angular CLI generates, checking the default title and welcome page.
